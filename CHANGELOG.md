# Changelog

## 0.1.0 (2026-11-08)

First release.

- Read-only hex viewer for files of any size. Only the rows on screen are read.
- "Open in Hex Viewer" in the Project view and editor tab menus, for any file.
- A Hex tab opens by itself for binary .bin, .dat, .exe, .dll, .so, .dylib, .o, .class and .wasm files, after the IDE's own editor when there is one.
- Go to offset, find hex (with ?? wildcards) or text, a data inspector, and copy as hex, C array, Python bytes or base64.
